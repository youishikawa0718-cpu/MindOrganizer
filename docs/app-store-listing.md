### Description (4000文字以内)
```
頭の中のモヤモヤをツリー形式で整理する、シンプルで美しい思考整理アプリです。

「やりたいこと」「悩み」「アイデア」を一度ツリーに書き出し、深掘りし、並べ替えるだけで、頭の中が驚くほど軽くなります。MindOrganizer は、外部サービスや過剰な機能に頼らず、思考を整理することそのものに集中できる体験を目指しました。

──────────
■ 主な機能
──────────

● ツリー編集
階層を持ったノードで思考を構造化。ドラッグ&ドロップで自由に並べ替えられます。最大20階層まで深掘り可能。

● マインドマップ表示
ツリーをそのまま放射状マインドマップで表示。全体の関係性をひと目で把握できます。

● タグ管理
ノードにカラフルなタグを付けて分類。タグから横断的に検索することも可能です。

● スナップショット
重要な節目でツリーを保存し、思考の変遷を後から振り返ることができます。

● マークダウンエクスポート
作成したツリーをマークダウン形式で書き出し、他のメモアプリやドキュメントと連携できます。

● ホーム画面ウィジェット
最近編集したテーマをホーム画面から素早く確認できます。

● 落ち着いたデザイン
紙のような質感の "Calm Paper" デザイン。長時間使っても目が疲れにくい配色。

──────────
■ プライバシー優先設計
──────────

・ローカル優先 — すべてのデータは端末内に保存され、オフラインでも全機能が動作します。
・ゲストモード — ログインせずに利用可能。データは端末から外に出ません。
・トラッキングなし — 広告・行動分析は一切行いません。
・アカウント削除 — 設定画面からワンタップでクラウドのデータを完全削除できます。

──────────
■ クラウド同期（オプション）
──────────

Apple Sign-In または Google Sign-In でログインすると、テーマ・ノード・タグ・スナップショットを複数デバイス間で自動同期します。同期には Firebase Authentication と Cloud Firestore を使用しています。

──────────
■ こんな方におすすめ
──────────

・考えがまとまらず、頭の中がいつもごちゃごちゃしている方
・ToDo アプリでは表現できない、階層的な思考を扱いたい方
・複雑なメモアプリは苦手で、シンプルさを大切にしたい方
・オフラインでも快適に動くノートアプリを探している方

「思考の整理は、書き出すことから始まる」
MindOrganizer がその最初の一歩を支えます。
```

## App Privacy Labels（App Store Connect 入力）

`MindOrganizer/PrivacyInfo.xcprivacy` と整合。

| Category | Data Type | Linked to User | Used for Tracking | Purposes |
|----------|-----------|:--:|:--:|----------|
| Contact Info | Email Address | Yes | No | App Functionality |
| Contact Info | Name | Yes | No | App Functionality |
| Identifiers | User ID | Yes | No | App Functionality |
| User Content | Other User Content | Yes | No | App Functionality |

**収集理由（審査用 英語メモ）**

| 項目 | Reason |
|------|--------|
| Email Address | Required for sign-in via Apple/Google and account recovery. |
| Name | Display name shown in the app's settings screen. Optional. |
| User ID | Firebase Authentication UID used to scope cloud-synced data to the user's account. |
| Other User Content | User-created themes, nodes, tags, and snapshots are synced across the user's devices via Cloud Firestore. |

**重要メモ**

- ゲストモードの場合は何も収集しない旨を App Privacy 説明欄に明記すると審査員に親切。
- Firebase Analytics / Crashlytics を将来追加する場合は、ラベルの再申告が必要。
